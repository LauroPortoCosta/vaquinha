vou construir um aplicativo : VAQUINHA, controle de gastos, e despesas compartilhadas  entre os participantes, com a seguinte estrutura : TELA DE ACESSO AO APLICATIVO, nome, senha, botão de  ( ACESSA ) , um rodapé discreto com ( cadastro, altera senha, etc. ) na segunda tela, tenho um SCROLL menu, com opções tipo : despesa, receita, grupos, lançamentos, categorias, extrato, minha conta etc. Cada item deste vira uma janela, onde a despesas vai existir : data, despesa ( posso escolher uma em um menu interno ), valor, que grupo participa este valor, uma opção onde posso apontar que parte deste valor é exclusivamente meu. Receita eu vou informar valor, data, e para qual grupo este crédito será direcionado. e sé parte deste crédito vai para um usuário especifico entre outras coisas. Grupos são usuários que se juntam para dividir um despesa, neste caso tenho que informar ao sistema que eu participo deste grupo. Exemplo : na lupa busco o grupo PORTO onde minha família divide um aluguel de pousada. Nesta tela previamente posso encontrar um grupo já formado mas também posso incluir um grupo novo do tipo PASSEIO, onde vou dividir despesas com todos aqueles que estiverem participando neste GRUPO. Tenho que pensar que cada pessoa no grupo pode assumir um numero de contas maior que o outro. Exemplo : no grupo de PASSEIO tenho 2 cotas pois irei assumir a minha participação e de minha esposa que não faz parte do aplicativo. LANÇAMENTOS, nesta nova tela tenho as compras os contratos, as aquisições que estão seno feitas para os participantes deste grupo. No momento dos lançamentos posso informar que parte daquele valor é pessoal, sendo assim ele não será rateado fincando em minha conta com despesas pessoais. Na opção de categoria posso cadastrar previamente nomes para que o aplicativo use para facilitar a digitação de despesas como : FARMACIA, SUPERMERCADO, BEBIDAS, ALUGUEL .... Uma nova janela deve existir para os extratos, como TOTAL, PARCIAL, PARTICULARES, POR TIPO DE DESPESAS etc. Acredito que ao desenvolver será nescessário a criação de novas janelas que no momento não consigo preve.
